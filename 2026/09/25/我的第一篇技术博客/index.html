从零搭建我的个人博客：折腾、踩坑与成长记录

写在前面：
这不是一篇详细的技术教程，而是一次属于我的折腾记录。
记录我如何从一个对 Web 开发几乎一无所知的新手，到亲手搭建出属于自己的个人博客。

起点：我为什么想拥有一个属于自己的博客？

其实最开始想搭博客，并没有什么特别宏大的目标。

只是有一天突然觉得：

“作为一个计算机专业的学生，如果连一个属于自己的网站都没有，好像总觉得少了一些什么。”

以前学习的时候，总觉得编程就是写代码、刷题、完成作业。

但是慢慢接触计算机之后，我发现真正有趣的地方在于：

你可以利用代码创造一些属于自己的东西。

一个网站、一套系统、一个工具，甚至只是一个简单的页面，都可以留下自己的痕迹。

所以我开始萌生了搭建个人博客的想法。

我希望它不仅仅是一个展示页面，更像是我的一个数字空间：

记录学习过程；

记录技术成长；

记录生活中的一些想法；

记录那些未来回头看，会觉得很有意义的瞬间。

第一次接触：从 Git 开始的迷茫

刚开始的时候，我甚至不知道 GitHub 到底是什么。

以前听别人说：

“程序员一定要会 GitHub。”

但是对于当时的我来说，GitHub 就像一个神秘的网站。

一打开，全是英文：

Repository？

Commit？

Branch？

Fork？

Pull Request？

每一个单词都认识，但是组合起来完全不知道是什么意思。

后来我开始一点点学习。

我才慢慢理解：

Git 是版本控制工具，就像给代码建立了一个时间机器。

GitHub 则像一个巨大的代码仓库，可以让全世界的开发者交流和分享。

第一次成功把自己的代码上传到 GitHub 的时候，其实挺开心的。

虽然只是简单的几个文件，但是那种感觉很奇妙：

“原来我写的东西，也可以出现在互联网里面。”

Hexo：第一次真正接触网站开发

后来了解到很多个人博客都是使用 Hexo 搭建的。

于是我开始尝试。

安装 Node.js。

配置环境。

安装 Hexo。

初始化博客。

部署到 GitHub Pages。

听起来很简单。

但是对于一个新手来说，每一步都充满了未知。

第一个问题：环境配置

刚开始配置环境的时候，经常出现各种奇怪的问题。

明明按照教程一步一步操作：

输入命令。

等待安装。

结果突然报错。

那种感觉真的很难受。

因为你不知道：

到底是哪里错了？

是 Node.js 的问题？

是 Git 的问题？

还是环境变量的问题？

有时候一个小问题，可以卡半个晚上。

但是解决之后，又会有一种特别强的成就感。

因为你知道：

这个问题不是别人帮你解决的，而是你自己真正理解了。

第一次部署成功：属于自己的第一个网站

当我第一次通过 GitHub Pages 打开自己的博客页面时。

那一刻真的挺激动。

虽然那个页面很简单。

没有精美的动画。

没有复杂的功能。

甚至看起来有一点简陋。

但是它是属于我的。

那一刻突然感觉：

以前只能浏览别人的网站。

现在，我也拥有了一个属于自己的角落。

美化博客：从能用到喜欢

搭建完成之后，我开始进入了漫长的美化阶段。

其实这一步比搭建本身花费的时间更多。

因为搭建只是让网站运行起来。

而美化，是让它拥有自己的灵魂。

我开始研究各种主题。

尝试不同的布局。

修改字体。

调整颜色。

设计主页。

添加个人信息。

增加社交链接。

甚至加入二次元元素，希望它更加符合自己的审美。

半夜修改代码的那些时间

不得不说，折腾博客真的会上瘾。

很多时候本来想着：

“今天改一点点，早点睡。”

结果：

改着改着发现一个问题。

想着解决一下。

解决之后又发现：

这里还能优化。

那里还能调整。

然后时间一点一点过去。

等反应过来的时候：

已经凌晨两三点。

电脑屏幕还亮着。

桌面上是一杯已经凉掉的水。

但是看到修改后的页面刷新出来的那一刻。

又觉得：

好像也值得。

有时候真的会因为一个小问题困扰很久。

比如：

为什么修改了头像但是没有生效？

为什么更换了封面之后本地预览打不开？

为什么配置文件改了但是页面没有变化？

这些问题现在看起来很简单。

但是当时真的会让人抓狂。

甚至怀疑：

是不是自己根本不适合学计算机？

但是后来发现：

计算机学习其实就是这样。

很多时候不是你不会。

而是你还没有找到问题在哪里。

程序员每天面对的事情，本质上就是：

发现问题。

分析问题。

解决问题。

然后继续遇到新的问题。

最大的收获：不是拥有一个博客

现在回头看。

搭建博客最大的收获，并不是最后这个网站。

而是在这个过程中，我真正接触到了很多以前陌生的东西：

  • Git 版本控制
  • GitHub 开源社区
  • Node.js 环境
  • Hexo 静态网站生成
  • Markdown 写作
  • 前端页面结构
  • CSS 样式修改
  • 网站部署流程

以前这些东西对我来说只是书本上的名词。

但是现在，它们变成了我亲手操作过的东西。

这种感觉很不一样。

写在最后

这个博客可能还不完美。

它可能还有很多可以优化的地方。

页面设计可能还不够惊艳。

代码结构可能还不够优秀。

但是它记录了我的一个开始。

从一个计算机专业的新手，到第一次拥有自己的个人网站。

这个过程里面有迷茫，有焦虑，有无数次想放弃的时候。

但是更多的是解决问题之后的快乐。

我相信以后我还会继续优化它。

也会继续学习更多东西。

可能未来某一天，我回头打开这篇文章，会觉得：

“当时的自己虽然什么都不懂，但是挺有热情。”

而这份热情，就是我继续走下去最大的动力。

愿每一个正在学习计算机的人，都能拥有属于自己的第一个作品。

哪怕它很简单，但它一定值得被记录。
